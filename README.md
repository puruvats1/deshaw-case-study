# Rethinking data visualization · D.E. Shaw case study

A single-page, scroll-driven case study. Plain HTML, CSS and a small script: no framework, no build step.

- `index.html`: content and pre-rendered diagram markup
- `styles.css`: all visuals and animation
- `main.js`: turns scroll position into CSS custom properties and `data-*` attributes

To preview locally, serve the folder with any static server, for example `npx http-server`.
